时间监狱 隐私政策

应用名称：时间监狱
开发者：陈平安（TapTap 开发者 ID 538035）
生效日期：2026-11-25

本政策仅适用于《时间监狱》。

一、我们收集哪些信息

本游戏不收集、不上传任何个人信息。

  • 没有账号系统，不需要登录、手机号或实名信息（如平台合规认证要求，由 TapTap SDK 在启动时完成，数据由平台处理）；
  • 不申请通讯录、位置、相机、麦克风、相册等权限；
  • 不接入统计、推送或用户画像 SDK；接入的第三方 SDK 只有广告与平台合规认证两类，清单见第五节；
  • 游戏运行所需的全部资源（语言、图标、画面）都打包在安装包内，离线可玩。

二、本地保存的数据

游戏只在本机保存一项数据：你的最高分（存在应用私有存储里）。它不会被上传，卸载应用即随之删除。

三、权限说明

  • 网络权限：用于平台合规认证与（如接入时）广告加载；游戏本体不联网也能玩；
  • 保持屏幕常亮：游玩期间不自动息屏，退出游戏即恢复系统默认行为；
  • 无其他敏感权限。

四、未成年人保护

游戏不含内购、社交与用户生成内容。未成年人保护与防沉迷由 TapTap 合规认证统一提供，游戏按平台返回的时段与时长限制执行。

五、第三方 SDK 清单

除以下两项外，我们不集成任何第三方 SDK：

  • TapADN 广告 SDK（上海艾得蒽数字科技有限公司）：用于激励视频广告的请求、展示与奖励核对，以及广告效果监测与反作弊。仅在玩家主动点击「看视频」时初始化并请求广告；处理网络状态、IP、设备标识（Android ID、OAID，可在系统设置中关闭）与广告展示/点击事件。SDK 隐私政策：ssp.dirichlet.cn/docs/agreement/
  • TapSDK 合规认证（TapTap / 易玩）：用于实名认证与防沉迷校验，处理平台账号标识与认证结果，不用于其他用途。

我们已关闭广告 SDK 的设备状态、MAC 地址、BSSID/SSID、位置、传感器、应用列表与外部存储采集开关，只保留广告归因必需的 Android ID 与 OAID。

六、数据共享与跨境传输

除上述平台合规认证与广告服务外，我们不向任何第三方提供、转让或公开你的数据。

七、政策更新

如果后续版本加入账号、排行榜或更多广告能力，我们会先更新本政策并在应用内说明。
